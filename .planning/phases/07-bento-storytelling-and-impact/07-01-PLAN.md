# Phase 07 - Plan 01: Bento Storytelling Integration

**Phase:** 07 - Bento Storytelling & Impact
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Extract quotes and update content models to support Bento Box layouts, then implement the grids on the Home and About pages. This will replace the "weird" gateway copy and weave media praise directly into the page flow.

Satisfies: `STORY-01`, `STORY-02`

## Tasks

### 07-01-01: Update Content Models (Home & About)
- **Goal:** Add quotes and fix homepage copy.
- **Action:**
  - Update `src/content/home.js`: Rewrite the audience gateway heading from "Find the next right page for your journey" to a more evocative phrase (e.g., "Step Into the Magic"). Add a `pressQuotes` array.
  - Update `src/content/about.js`: Add a `testimonials` array with quotes from campers and staff.
- **Verification:** `npm run test`.

### 07-01-02: Implement Homepage Bento Grid
- **Goal:** Redesign the `HomeRoute.jsx` layout.
- **Action:**
  - Convert the `home-why-title` section from a standard 2-up stack into an asymmetrical CSS Grid (e.g., 12-column grid on `lg` breakpoints).
  - Inject the extracted press quotes as bold, colored visual blocks within this grid.
- **Verification:** `npm run test`.

### 07-01-03: Implement About Page Bento Grid
- **Goal:** Redesign the `AboutRoute.jsx` layout.
- **Action:**
  - Refactor the "Belonging" and "Activities" sections into a Bento layout.
  - Integrate the camper/staff quotes seamlessly into the grid alongside the standard content cards.
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest rendering checks.
- **Manual:** Resize the browser window to ensure the complex grids stack linearly on mobile without visual glitches.
