# Phase 07 - Plan 02: Donor Impact Dashboard

**Phase:** 07 - Bento Storytelling & Impact
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Add a visually striking, data-driven "Impact Dashboard" to the Donate page to highlight the camp's scale and success to major donors and foundations.

Satisfies: `IMP-01`

## Tasks

### 07-02-01: Define Dashboard Content
- **Goal:** Add static metrics to the content layer.
- **Action:**
  - Update `src/content/donate.js` with an `impactMetrics` array containing the static data points: "140+ Campers," "30 States," "50+ Staff," "4 Summers," etc.
- **Verification:** `npm run test`.

### 07-02-02: Build the Impact Dashboard Component
- **Goal:** Render the metrics visually.
- **Action:**
  - Update `src/routes/DonateRoute.jsx` to include a new grid section specifically for these metrics.
  - Use `lucide-react` icons and large typography (e.g., `text-5xl font-extrabold text-[var(--color-camp-orange)]`) for the numbers to draw the eye immediately.
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest rendering checks for the new metrics.
- **Manual:** Verify the dashboard commands attention and feels distinct from the standard text content on the page.
