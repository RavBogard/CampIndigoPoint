# Phase 03 - Plan 01: Distinct Character and Queer Storytelling

**Phase:** 03 - Family Trust and Registration Journey
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Replace generic layouts with distinct, high-energy storytelling for the "About" and "Registration" pages. Ensure every page has its own "soul"—from the "Adventure" of camp life to the "Care" of the registration and affordability path.

Satisfies: `FAM-01`, `FAM-02`, `FAM-03`, `FAM-04`, `FAM-05`, `TRST-01`

## Tasks

### 03-01-01: Build "The Adventure" (About Page)

- **Goal:** Transform the About page into a high-energy "Day in the Life" storytelling journey.
- **Action:**
  - Update `src/content/about.js` with specific, evocative "magic moments" (campfire, lake joy, friend-making).
  - Add specific sections for "Names, Pronouns, and Belonging" (Community Care).
  - Modify `src/routes/AboutRoute.jsx` to use a "wavy" or "organic" stacked layout with large activity photos.
- **Verification:** `npm run test` (About route smoke test).

### 03-01-02: Build "The Care" (Registration Page)

- **Goal:** Refocus the Registration page on support, affordability, and the "No One Turned Away" promise.
- **Action:**
  - Update `src/content/registration.js` to lead with the "heart" of registration—ensuring every kid can come, regardless of cost.
  - Detail the "External Handoff" to Active Camps as a simple, guided next step.
  - Modify `src/routes/RegistrationRoute.jsx` to use a warmer, more "hand-holding" layout that reduces registration anxiety.
- **Verification:** `npm run test` (Registration route smoke test).

### 03-01-03: Visual "Soul" Polish (CSS)

- **Goal:** Add camp-specific visual flourishes that break the "business" grid.
- **Action:**
  - Update `src/index.css` with organic "blob" shapes, sunlight gradients, and pride-accented dividers.
  - Ensure every page feels different while staying within the core Teal/Orange/Warm-Sand palette.
- **Verification:** Browser check of visual character.

- **Manual:** Verify that each page feels "distinct" and "queer" in tone and visual energy.
