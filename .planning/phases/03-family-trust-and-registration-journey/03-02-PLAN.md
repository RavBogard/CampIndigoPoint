# Phase 03 - Plan 02: Brand and Authentic Media Migration

**Phase:** 03 - Family Trust and Registration Journey
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Replace placeholder branding and imagery with real Camp Indigo Point assets to establish immediate trust and recognition.

Satisfies: `TRST-01`, `BRAND-01`, `BRAND-02`

## Tasks

### 03-02-01: Migrate Core Brand Assets

- **Goal:** Replace the shell's badge with the real logo and update favicon/OG metadata.
- **Action:**
  - Download the live logo and create local assets: `public/brand/logo.png`, `public/brand/favicon.png`.
  - Update `src/components/site/SiteHeader.jsx` to use the new logo.
  - Update `src/content/meta.js` and `src/lib/metadata.js` for the OG image path.
- **Verification:** `npm run build` (Static asset check).

### 03-02-02: Integrate Family Storytelling Media

- **Goal:** Add authentic camp photos into the family routes with a clean content model.
- **Action:**
  - Download 3-5 curated photos from the live site and store them in `public/images/families/`.
  - Create a `familyMedia` structure in `src/content/site.js` (or a dedicated module).
  - Update routes to use the new `media` prop in `PageFrame` (from Plan 01).
- **Verification:** `npm run test` (Logo and image rendering).

### 03-02-03: Visual Branding Refinement

- **Goal:** Tune CSS to ensure the real logo and images fit the design seamlessly.
- **Action:**
  - Update `src/index.css` for header logo sizing, image aspect ratios, and mobile stacks.
  - Refine card and media layouts to handle different image orientations gracefully.
- **Verification:** `npm run build` (CSS check).

## Validation Strategy

- **Automated:** Asset existence check in `npm run build`.
- **Manual:** Verify the header logo and image responsiveness in the browser.
