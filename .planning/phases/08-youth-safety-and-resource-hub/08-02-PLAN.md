# Phase 08 - Plan 02: Interactive Resource Hub (FAQ)

**Phase:** 08 - Youth Safety UX & Resource Hub
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Refactor the static FAQ page into a dynamic, filterable Resource Hub using Framer Motion to ensure smooth transitions between content categories.

Satisfies: `HUB-01`

## Tasks

### 08-02-01: Refactor FAQ Data Structure
- **Goal:** Make the FAQ data filterable.
- **Action:**
  - Update `src/content/faq.js`. Change the `groups` object into a flat array named `items`.
  - Add a `category` property (e.g., 'Families', 'Donors', 'Staff') to each object in the array.
- **Verification:** `npm run test` (Content structure).

### 08-02-02: Build the Resource Hub UI
- **Goal:** Implement the filterable component.
- **Action:**
  - Update `src/routes/FaqRoute.jsx`.
  - Add a state variable `[activeCategory, setActiveCategory] = useState('All')`.
  - Create a row of filter buttons ("All", "Families", "Donors", "Staff") that update the state.
  - Filter the `faqPage.items` array based on the `activeCategory`.
- **Verification:** `npm run test`.

### 08-02-03: Animate with Framer Motion
- **Goal:** Add smooth entry/exit animations.
- **Action:**
  - Import `motion` and `AnimatePresence` from `framer-motion`.
  - Wrap the mapped, filtered FAQ list in `<AnimatePresence mode="popLayout">`.
  - Replace the `<article>` tag for each FAQ item with `<motion.article>` and add `initial`, `animate`, and `exit` props (e.g., opacity fade and slight y-axis slide).
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest rendering checks for the buttons and the filtered list.
- **Manual:** Click the filter buttons and verify that the correct questions appear and that the transition is smooth without jarring layout jumps.
