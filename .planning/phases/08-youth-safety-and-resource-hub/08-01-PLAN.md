# Phase 08 - Plan 01: Quick Exit Implementation

**Phase:** 08 - Youth Safety UX & Resource Hub
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Build and integrate the "Quick Exit" panic button to provide a critical safety feature for youth browsing the site in unsupportive environments.

Satisfies: `SAFE-01`, `SAFE-02`

## Tasks

### 08-01-01: Build the QuickExit Component
- **Goal:** Create the standalone React component.
- **Action:**
  - Create `src/components/site/QuickExit.jsx`.
  - Implement an `onClick` handler that calls `window.location.replace('https://weather.com')`.
  - Implement a `useEffect` to listen for the 'Escape' key, tracking rapid successive presses to trigger the same redirect.
  - Style it as a fixed, highly visible button (`fixed bottom-4 right-4 z-[100]`) using Tailwind. Use `lucide-react` for an 'X' or 'External Link' icon.
- **Verification:** `npm run test` (Component rendering smoke test).

### 08-01-02: Integrate Globally
- **Goal:** Ensure the button persists across the entire site.
- **Action:**
  - Import and render `<QuickExit />` inside `src/components/site/SiteLayout.jsx`.
- **Verification:** `npm run test` (Site layout rendering smoke test).

## Validation Strategy
- **Automated:** Vitest to ensure `SiteLayout` still mounts correctly with the new component.
- **Manual:** Click the button and verify immediate redirect. Press 'Escape' repeatedly and verify redirect.
