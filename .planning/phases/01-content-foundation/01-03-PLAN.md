# Phase 1 Plan 03: Define Metadata and Announcement Patterns

## Objective
- **What:** Create reusable metadata and seasonal notice structures that later phases can plug into the rebuilt site shell.
- **Why:** Phase 1 owns the content/modeling layer, and metadata plus announcements are explicitly part of the phase success criteria.
- **Output:** A metadata module, a finalized sitewide announcement schema, and maintainer-facing update guidance for content operations.

## Success Criteria
- A reusable metadata source exists for primary page domains.
- The seasonal banner model is single-slot, manual-toggle, and milestone-focused.

- Page titles and descriptions no longer depend on later ad hoc decisions.
