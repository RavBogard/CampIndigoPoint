# Phase 1 Plan 01: Establish Content Source of Truth

## Objective
- **What:** Create the core content/config scaffolding for Camp Indigo Point so later phases build against centralized source files rather than inline JSX.
- **Why:** This is the lowest-risk way to protect trust-critical content and outbound actions before the app shell is redesigned.
- **Output:** Foundational `src/content/` files for site settings, brand facts, action links, and a WordPress migration inventory.
