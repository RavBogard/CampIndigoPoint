# Phase 10 - Plan 01: Hero Slideshow Implementation

**Phase:** 10 - Hero Slideshow & Media Density
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Build a smooth, crossfading Hero Slideshow component and integrate it into the homepage to immediately showcase the depth of joy at Camp Indigo Point.

Satisfies: `MEDIA-02`

## Tasks

### 10-01-01: Build HeroSlideshow Component
- **Goal:** Create a reusable animated slideshow component.
- **Action:**
  - Create `src/components/site/HeroSlideshow.jsx`.
  - Use `useState` and `useEffect` with `setInterval` (e.g., 5000ms) to cycle through an array of images.
  - Use `framer-motion` (`<AnimatePresence>` and `<motion.img>`) to create a smooth, 1-second crossfade between images.
- **Verification:** `npm run test`.

### 10-01-02: Integrate Slideshow into HomeRoute
- **Goal:** Replace the static image on the homepage.
- **Action:**
  - Update `src/content/home.js` to include a `heroGallery` array of 3-5 high-quality image objects (src, alt).
  - Modify `src/components/site/PageFrame.jsx` to accept a React Node for the `media` prop, allowing the `HeroSlideshow` to be passed in.
  - Render `<HeroSlideshow images={homePage.heroGallery} />` inside `HomeRoute.jsx` and pass it to `PageFrame`.
- **Verification:** `npm run test` (Render smoke test).

## Validation Strategy
- **Automated:** Vitest rendering checks for `HeroSlideshow` and updated `PageFrame`.
- **Manual:** Open the homepage in the browser and watch the slideshow cycle through at least one full rotation to ensure the transitions are smooth and the layout does not jump.
