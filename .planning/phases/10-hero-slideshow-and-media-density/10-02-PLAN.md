# Phase 10 - Plan 02: Site-Wide Media Density

**Phase:** 10 - Hero Slideshow & Media Density
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Systematically weave the new gallery photos into the text-heavy routes (Registration, Donate, Staff, FAQ, Contact) using best-practice UI layout grids to eliminate "walls of text."

Satisfies: `MEDIA-03`

## Tasks

### 10-02-01: Curate Photos for Routes
- **Goal:** Assign specific gallery photos to specific routes in the content layer.
- **Action:**
  - Update `src/content/registration.js`, `donate.js`, `staff.js`, `faq.js`, and `contact.js` to include new `supportingPhotos` arrays (or single `supportImage` properties) pointing to the `public/images/gallery/` assets.
- **Verification:** `npm run test`.

### 10-02-02: Integrate Photos into UI Layouts
- **Goal:** Render the curated photos beautifully within the page grids.
- **Action:**
  - Update the respective `Route.jsx` files.
  - Instead of just dropping `<img>` tags, use Tailwind grid positioning (e.g., making a photo span a column next to a text block) or place them inside `content-card` containers with `aspect-video` and `object-cover` classes to maintain the "organic" brand shapes.
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest rendering checks to ensure new image nodes are present.
- **Manual:** Review every updated route to ensure the text-to-image ratio feels balanced and the layouts don't break on mobile viewports.
