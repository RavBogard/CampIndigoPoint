# Phase 05 - Plan 02: Contact Routing and Press Integration

**Phase:** 05 - Staff Recruiting and Contact Journey
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Evolve the Contact page from a generic directory into an explicitly routed experience based on visitor intent, and integrate a new "Camp Indigo Point in the Press" section to build authority.

Satisfies: `TRST-02`, `TRST-01`

## Tasks

### 05-02-01: Update Contact Content Model
- **Goal:** Provide explicit routing options in the content layer.
- **Action:**
  - Create or update `src/content/contact.js` (or `brand.js`) to categorize contacts by intent (e.g., "Registration & Scholarships -> Dan", "Nursing & Accommodations -> Shira").
  - Add a new data structure for `pressLinks` (Washington Post, NYT, GMA, etc.).
- **Verification:** `npm run test` (Content structure).

### 05-02-02: Compose Contact and Press Route
- **Goal:** Update `ContactRoute.jsx` to guide the user and display authority.
- **Action:**
  - Refactor `ContactRoute.jsx` to show categorized "Who to contact" cards.
  - Build a new `PressSection` component (or inline section) that iterates over the `pressLinks` and displays them prominently.
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Route rendering checks in Vitest for the Contact and Press elements.
- **Manual:** Verify the clarity of the contact routing and the visual credibility of the Press section.
