# Phase 2 Plan 01: Establish Routing and Shared Shell Foundation

## Objective
- **What:** Replace the current single-page starter composition with a route-based application shell that can host all primary Camp Indigo Point pages.
- **Why:** Phase 2 needs a stable structural baseline before navigation, CTA persistence, and accessibility work can be layered on safely.
- **Output:** Route definitions, route components for primary destinations, a shared layout/footer foundation, and route metadata wiring built on the new content modules.
