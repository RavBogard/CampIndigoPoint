# Phase 11 - Plan 01: Interactive "Day in the Life" Timeline

**Phase:** 11 - Conversion UX Optimization
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Upgrade the "Camp Life" section on the About page from a static list into a highly visual, clickable interactive timeline.

Satisfies: `CONV-02`

## Tasks

### 11-01-01: Refactor Content Data
- **Goal:** Structure the data for a timeline.
- **Action:**
  - Update `src/content/about.js`. Change `campLife.bullets` into `campLife.schedule`, an array of objects: `{ time, title, description }`.
- **Verification:** `npm run test`.

### 11-01-02: Build the Timeline Component
- **Goal:** Create the visual timeline.
- **Action:**
  - Build `<CampTimeline schedule={aboutPage.campLife.schedule} />` in `src/components/site/`.
  - Use Tailwind to draw a vertical line and place dots along it.
  - Use `framer-motion` (`initial`, `whileInView`, `viewport={{ once: true }}`) to make the timeline items slide in as the user scrolls.
- **Verification:** `npm run test`.

### 11-01-03: Integrate into AboutRoute
- **Goal:** Replace the old static list.
- **Action:**
  - Update `src/routes/AboutRoute.jsx` to render the `<CampTimeline />` instead of the mapped `<ul>` list.
- **Verification:** `npm run test` (render smoke test).

## Validation Strategy
- **Automated:** Vitest rendering checks for the new component.
- **Manual:** Scroll down the About page to ensure the timeline items animate smoothly into view and do not overlap.
