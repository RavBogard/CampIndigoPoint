# Phase 11 - Plan 02: Sticky Action Bar

**Phase:** 11 - Conversion UX Optimization
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Implement a persistent, scroll-aware Sticky Action Bar that displays the relevant primary CTA based on the user's current route.

Satisfies: `CONV-01`

## Tasks

### 11-02-01: Build the StickyActionBar Component
- **Goal:** Create the scroll-aware bar.
- **Action:**
  - Create `src/components/site/StickyActionBar.jsx`.
  - Use `framer-motion`'s `useScroll` and `useMotionValueEvent` to track scroll position. If `scrollY > 400`, set `isVisible = true`.
  - Animate the bar sliding up from the bottom: `<motion.div initial={{ y: 100 }} animate={{ y: isVisible ? 0 : 100 }} className="fixed bottom-0 left-0 right-0 z-40 bg-white/95 backdrop-blur-md shadow-[0_-10px_40px_rgba(0,0,0,0.1)] p-4 border-t-4 border-[var(--color-camp-orange)] flex justify-center">`.
- **Verification:** `npm run test`.

### 11-02-02: Add Context-Aware Logic
- **Goal:** Show the right CTA for the right audience.
- **Action:**
  - Use `useLocation()` to check the current path.
  - If path includes `/donate`, render the Donate CTA. If `/staff`, render the Apply CTA. Otherwise (default), render the Register CTA.
- **Verification:** `npm run test`.

### 11-02-03: Integrate Globally
- **Goal:** Ensure the bar is available everywhere.
- **Action:**
  - Import and render `<StickyActionBar />` inside `SiteLayout.jsx` (or `PageFrame.jsx` if preferred to keep it out of the absolute highest level). `SiteLayout.jsx` is best so it persists even during route transitions.
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest rendering check for `StickyActionBar`.
- **Manual:** Scroll down a long page. Ensure the bar appears. Ensure it does NOT block the footer links or the mobile navigation drawer.
