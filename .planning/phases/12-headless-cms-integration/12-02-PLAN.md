# Phase 12 - Plan 02: Decap CMS Configuration

**Phase:** 12 - Headless CMS Integration
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Install Decap CMS and configure its `config.yml` to perfectly map to our new JSON data structures, providing a user-friendly dashboard.

Satisfies: `OPS-03`

## Tasks

### 12-02-01: Setup CMS Admin Route
- **Goal:** Create the admin entry point.
- **Action:**
  - Create `public/admin/index.html` loading the Decap CMS script via CDN.
- **Verification:** `npm run build`.

### 12-02-02: Map Collections to config.yml
- **Goal:** Define the editable fields.
- **Action:**
  - Create `public/admin/config.yml`.
  - Configure the `backend` for local proxy development and Git gateway production.
  - Define a `pages` collection (file-based) mapping to `home.json`, `about.json`, etc.
  - Define `lists` collections for FAQs and Contact Directory.
  - *Crucial:* Ensure every field in the YAML maps exactly to the expected JSON key (e.g., `widget: "list", name: "heroGallery"`).
- **Verification:** Start `npx decap-server` and verify the config parses without errors.

## Validation Strategy
- **Automated:** None.
- **Manual:** Log into the local CMS dashboard, make a change to a text field, save it, and verify the corresponding `src/content/data/*.json` file updates locally.
