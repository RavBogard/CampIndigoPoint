# Phase 12 - Plan 01: JSON Data Migration

**Phase:** 12 - Headless CMS Integration
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Convert the existing JavaScript content modules into static JSON files so Decap CMS can edit them without breaking the React architecture.

Satisfies: `OPS-03`

## Tasks

### 12-01-01: Convert Content to JSON
- **Goal:** Move data from `.js` to `.json`.
- **Action:**
  - Create `src/content/data/` directory.
  - Convert `home.js`, `about.js`, `donate.js`, `registration.js`, `staff.js`, `faq.js`, and `brand.js` into equivalent `.json` files.
  - *Note:* We must strip out the `actionLinks` references and hardcode them as strings in the JSON, as JSON cannot resolve JS variables. We will handle re-mapping the actions in the components.
- **Verification:** `npm run build`.

### 12-01-02: Update React Imports
- **Goal:** Point React to the new JSON files.
- **Action:**
  - Update all `Route.jsx` components to import the new `.json` files instead of the old `.js` files.
  - Refactor any logic that relied on dynamic JS resolution (like the action links) to look up the correct object based on the string ID in the JSON.
- **Verification:** `npm run test` (Render smoke tests must pass with new JSON data).

## Validation Strategy
- **Automated:** The Vitest suite must run perfectly, confirming that the structure of the JSON exactly matches the structure React expects.
- **Manual:** Check the browser to ensure the site still loads and looks exactly as it did before the migration.
