# Phase 06 - Plan 01: Tailwind Architecture Initialization

**Phase:** 06 - UI and Tailwind CSS Refactor
**Plan:** 01
**Wave:** 1
**Status:** draft

## Objective

Integrate Tailwind CSS into the Vite build pipeline and configure the theme to perfectly match the existing "Soul & Story" brand identity.

Satisfies: `ARCH-01`, `ARCH-02`, `BRND-01`

## Tasks

### 06-01-01: Install and Configure Tailwind CSS
- **Goal:** Add Tailwind to the project.
- **Action:**
  - Install `tailwindcss`, `@tailwindcss/vite` (or equivalent based on Vite version).
  - Update `vite.config.js` to include the Tailwind plugin.
  - Create the base `src/tailwind.css` file and import it into `src/main.jsx`.
- **Verification:** `npm run build` (Ensures build pipeline still works).

### 06-01-02: Port Brand Tokens to Tailwind Theme
- **Goal:** Ensure Tailwind uses the Camp Indigo Point colors and fonts.
- **Action:**
  - Update the Tailwind configuration (either in `tailwind.config.js` or via `@theme` in `tailwind.css` for v4) to include:
    - Colors: `accent` (#1f5f7a), `accent-warm` (#e17a2d), `bg-warm` (#fffaf5).
    - Fonts: `sans` (Quicksand), `serif` (Montserrat).
    - Safelist or define custom classes for complex wavy shapes if they cannot be built with pure utilities.
- **Verification:** `npm run build`.

## Validation Strategy
- **Automated:** Vite build success.
- **Manual:** Check the browser to ensure the site still loads (even if styling looks broken initially while classes are swapped).
