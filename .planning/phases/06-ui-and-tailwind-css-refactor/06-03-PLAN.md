# Phase 06 - Plan 03: Route Refactor and CSS Cleanup

**Phase:** 06 - UI and Tailwind CSS Refactor
**Plan:** 03
**Wave:** 3
**Status:** draft

## Objective

Systematically replace custom classes in all individual route components with Tailwind utilities, and completely gut the legacy `index.css` file to finalize the migration.

Satisfies: `LAY-01`, `LAY-02`, `RES-01`, `RES-02`, `BRND-01`

## Tasks

### 06-03-01: Refactor High-Traffic Routes (Home, About)
- **Goal:** Convert the most complex layouts to utility classes.
- **Action:**
  - Update `HomeRoute.jsx`: convert Audience Path cards to a responsive grid.
  - Update `AboutRoute.jsx`: recreate the "wavy" visual panels using Tailwind utilities (e.g., asymmetrical rounded corners and background colors).
- **Verification:** `npm run test`.

### 06-03-02: Refactor Conversion Routes (Registration, Donate, Staff, Contact)
- **Goal:** Convert the remaining routes.
- **Action:**
  - Update `RegistrationRoute.jsx`, `DonateRoute.jsx`, `StaffRoute.jsx`, and `ContactRoute.jsx`.
  - Convert `content-card--affirming` logic to inline Tailwind utility classes (e.g., `bg-pink-50 border-l-4 border-pink-600`).
- **Verification:** `npm run test`.

### 06-03-03: Eradicate Legacy index.css
- **Goal:** Remove the source of layout bugs.
- **Action:**
  - Systematically delete all layout, spacing, and sizing rules from `src/index.css`.
  - Retain ONLY rules that are absolutely necessary and cannot be handled by Tailwind (which should be near zero).
- **Verification:** `$gsd-verify-work` (Full build and test suite).

## Validation Strategy
- **Automated:** Full Vitest suite passes.
- **Manual:** Exhaustive browser audit across all viewports to guarantee 0 layout bugs, 0 horizontal scroll, and 100% preservation of the "Soul & Story" aesthetic.
