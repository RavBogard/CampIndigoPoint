# Phase 06 - Plan 02: Global Shell Refactor

**Phase:** 06 - UI and Tailwind CSS Refactor
**Plan:** 02
**Wave:** 2
**Status:** draft

## Objective

Refactor the persistent global components (Header, Footer, Layout, PageFrame) to use Tailwind utility classes, establishing the responsive grid and flexbox foundations for the rest of the site.

Satisfies: `LAY-01`, `LAY-02`, `RES-01`

## Tasks

### 06-02-01: Refactor SiteHeader and Navigation
- **Goal:** Replace brittle header CSS with Tailwind utilities.
- **Action:**
  - Update `SiteHeader.jsx` to use flexbox utilities for logo and nav alignment.
  - Ensure the mobile menu hamburger icon and drawer (`MobileNavDrawer.jsx`) position correctly using utility classes.
- **Verification:** `npm run test` (Component rendering).

### 06-02-02: Refactor PageFrame and Container Logic
- **Goal:** Establish the primary layout wrapper.
- **Action:**
  - Update `PageFrame.jsx` to use a standard `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` container pattern.
  - Refactor the hero section within `PageFrame` to use a responsive flex or grid layout for text and media.
- **Verification:** `npm run test`.

### 06-02-03: Refactor SiteFooter
- **Goal:** Convert the footer grid to Tailwind.
- **Action:**
  - Update `SiteFooter.jsx` to use a responsive grid (`grid-cols-1 md:grid-cols-2 lg:grid-cols-4`).
- **Verification:** `npm run test`.

## Validation Strategy
- **Automated:** Vitest component tests pass.
- **Manual:** Verify the header, footer, and basic page constraints work flawlessly on mobile and desktop without horizontal scroll.
